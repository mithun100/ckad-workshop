## Why this format

The five-beat, break-it-on-purpose teaching pattern in this workshop comes directly from
what actually moved the needle when preparing for these exams: repetition on real clusters,
and getting comfortable diagnosing failures rather than only creating resources that work on
the first try. The workshop is the format I wish I'd had.
